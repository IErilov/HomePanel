# Home portal by Erilov Ilya — frontend

Базовый интерфейс файлового портала на Vue 3 + Vite с Bootstrap 5.2.0-beta1.

## Навигация
- `/` — открывает `/app` и для гостей, и для авторизованных пользователей.
- `/app` — единственная рабочая страница: файловое пространство со списком доступных бакетов и файлов.
- `/login` — вход в существующий аккаунт. Если токен уже есть, переход на `/app`.
- `/register` — перенаправление на `/login`; регистрации в интерфейсе нет.

В боковом меню оставлена только ссылка «Файловое пространство». Выбор доступного бакета остаётся внутри этой страницы.

## Возможности файловой страницы
- просмотр доступных хранилищ и файлов;
- поиск и сортировка;
- загрузка и скачивание;
- переименование и удаление с учётом прав backend;
- светлая и тёмная темы.

## API
Используются существующие endpoints:
- `POST /api/users/login`
- `GET /api/users/me`
- `GET /api/buckets/`
- `GET /api/buckets/{bucket_id}/files`
- `POST /api/buckets/{bucket_id}/upload`
- `GET /api/buckets/{bucket_id}/download/{filename}`
- `DELETE /api/buckets/{bucket_id}/files/{filename}`
- `PATCH /api/buckets/{bucket_id}/files/{filename}`

Backend должен предоставлять публичный `GET /api/buckets/`: гостю — доступные OPEN бакеты, авторизованному пользователю — OPEN и его PERSONAL бакеты. Frontend дополнительно фильтрует список гостя до `OPEN`; PERSONAL не показываются даже если случайно пришли в ответе API.

## UI
- Bootstrap 5.2.0-beta1 подключён глобально; прикладные компоненты оформляются поверх него через CSS-переменные.
- Светлая тема использует нейтральные поверхности и синий акцент; тёмная — почти чёрные поверхности и мягкий голубой акцент.
- Цвета элементов управления, таблиц, полей ввода, уведомлений и меню согласованы между темами.
- Переключение темы имеет короткий переход без масштабирования и декоративных эффектов; тема применяется до монтирования Vue, чтобы избежать вспышки неправильной палитры.
- Добавлена адаптивная стилизация LandingView, файлового пространства и формы входа.
- Микроанимации используются только для обратной связи (hover, меню, модальное окно); учитывается `prefers-reduced-motion`.
- Гостевой маршрут открывает файловое пространство; гостям показываются только OPEN-бакеты. Истёкший токен сбрасывается с переходом в гостевой режим, а не отправляет пользователя на экран входа.

## Сборка
```bash
npm install
npm run build
```

В Docker сборка выполняется frontend Dockerfile.


## Исправление отображения OPEN-бакетов
- Backend сериализует `BucketType` в нижнем регистре (`open`, `personal`), frontend теперь нормализует типы в верхний регистр при получении списка.
- Фильтрация гостевого списка, распознавание OPEN/PERSONAL, иконки и подписи используют нормализованный тип.
- Исправлено отображение публичных бакетов и на странице LandingView.
